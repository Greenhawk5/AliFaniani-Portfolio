## 1. Architectural Summary & Major Workstreams

The v2.5.0 milestone represents a major evolution of the portfolio, maturing the CMS, administration, 3D graphics engine, mobile responsive layout, and infrastructure monitoring into an integrated, enterprise-grade architecture.

### Workstream 1: CMS Selective Publishing & Deterministic Sync Pipeline
- **Selective Promotion:** Replaced monolithic "publish all" with a granular checkbox-driven draft selection system (`PublishingView.tsx`, `publish.ts`).
- **Visual Diffing:** Visual diff indicators showcase whether an item is a new record, draft overlay on published content, or archived record.
- **Publishing State Machine:** Managed via Cloudflare KV `deploy:state` (`pending_sync`, `sync_dispatch_failed`, `queued`, `trigger_failed`).
- **Snapshot Sync Retry:** Enabled direct re-dispatch of GitHub Actions snapshot sync workflows from the administrative interface.
- **Ordered Deployment Guarantee:** The Cloudflare Pages deploy hook is dispatched *only after* the regenerated snapshot (`content.json` and `sitemap.xml`) is committed to `main` via GitHub Actions (`cms-snapshot-sync.yml`).

### Workstream 2: Responsive 3D Room Camera Architecture & Mobile Controls
- **Bounding-Box Framing:** Dynamically computes object dimensions via `box.getSize()` in `CameraRig.tsx` to set camera distance, focal length, and vertical look offset based on device aspect ratio (portrait vs landscape).
- **Mobile Touch Orbit:** Single-finger drag with momentum damping for smooth rotation.
- **Two-Finger Pinch-to-Zoom:** Natural pinch gestures for zooming in and out on touch devices.
- **Virtual Freecam Joystick:** On-screen thumb joystick for free-camera navigation on touch screens, paired with touch-look gestures.
- **Vertical Pitch Clamping:** Enforced strict pitch limits to prevent camera flipping or looking into floor geometry.
- **Controls Drawer Separation:** Reorganized UI to separate camera perspective presets (Overview, Workstation, Shelf, Freecam) from scene interactions.

### Workstream 3: Admin Panel Modernization (SEO, Integrations, Settings)
- **Zero-Trust Diagnostics Probe:** Built `functions/api/admin/system/health.ts` and `src/admin/systemApi.ts` to inspect D1 latency, table record counts, KV state, R2 media accessibility, and edge runtime data without exposing credentials.
- **Session Probe Mode:** Health checks use `isProbe: true` so monitoring probes never artificially extend idle session expiration.
- **SEO Center Overhaul:** Actionable diagnostic checks, canonical validation, route-by-route inspection table, and direct jump-to-remedy navigation links.
- **Integrations & Infrastructure Registry:** Honest observed evidence across 10 distinct cloud services and a 6-stage publishing pipeline diagram.
- **Admin Settings Center:** 5 structured domains (*Account & Session*, *Application & Build*, *Content & Publishing*, *Infrastructure & Bindings*, *Security & Secrets*), copyable version tokens, and safe sign-out workflow.

### Workstream 4: Mobile Responsive Layout & Typography Adaptive Fit
- **Fluid Hero Typography:** Re-engineered Homepage hero title using CSS `clamp(2.5rem, 8vw, 4.25rem)` to eliminate horizontal layout overflows.
- **Selected Work Multi-Line Wrapping:** Refactored `ProjectCarousel.tsx` to allow natural multi-line wrapping for long project titles, subtitles, and category badges without clipping or awkward ellipses.
- **Consistent Card Padding:** Adjusted responsive card heights and container boundaries across mobile viewports down to 320px.

### Workstream 5: Google Search Site Name & Structured Data
- **OpenGraph Site Name:** Updated `og:site_name` from `"Ali Faniani Portfolio"` to `"Ali Faniani"`.
- **JSON-LD Schema Markup:** Configured `WebSite` entity inside `@graph` with `name: "Ali Faniani"` and `alternateName: ["AliFaniani", "Ali Faniani Portfolio"]`.
- **SSR Prerendering:** Generated static HTML shells with identical metadata so search bots without JavaScript receive complete identity signals.
