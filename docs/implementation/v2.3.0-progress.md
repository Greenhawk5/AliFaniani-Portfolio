## 2. Key Technical Achievements & Evidence

### 2.1 3D Room Performance Fix (Verified Smoking Gun)
- **Problem:** `boardScreen.ts` set `transitionStart = performance.now() / 1000` while `ProjectBoard.tsx` called `renderer.update(env.time)`. Because `env.time` started at 0 and was thousands of seconds behind `performance.now() / 1000`, transitions never concluded (`t >= 1` never evaluated to true), permanently locking navigation (`if (transitionStart >= 0) return`) and causing `renderer.update()` to return `true` on EVERY frame at 60/120 Hz, forcing continuous VRAM uploads of the 1024x620 texture.
- **Solution:**
  - Unified the clock domain using `performance.now() / 1000`.
  - Implemented dirty-flag rendering with an offscreen pre-rendered background canvas (eliminating 52 canvas stroke operations per frame).
  - During idle states (between slide switches), `renderer.update()` returns `false`, achieving 0% GPU texture upload overhead during idle.
  - Reduced slide transition duration to a crisp 350ms with zero dropped clicks.

### 2.2 First-Party Privacy-Preserving Analytics
- **Migration 0006:** Added `page_view_events`, `analytics_daily`, `project_analytics_daily`, and `admin_notifications` tables with covering indexes.
- **Privacy Guarantee:** Daily rotating salted SHA-256 session hash (`sha256Hex(ip::ua::date::salt)`). Raw IP addresses are NEVER stored in analytics.
- **Bot Filtering:** Rigorous regex filters out search bots, crawlers, Lighthouse, and headless browsers.
- **Public Stats:** `GET /api/analytics/stats` returns cacheable counts (`Cache-Control: public, max-age=60, s-maxage=300`).
- **Client Beacon:** `src/hooks/useAnalyticsTracker.ts` uses asynchronous `navigator.sendBeacon` for non-blocking telemetry.
