## 3. Phase 1 Implementation Summary (Session Security & Audit Foundation)
- **15-Minute Inactivity & 12-Hour Absolute Timeout:**
  - Enforced server-side in `functions/lib/sessions.ts` via `evaluateSession`.
  - Write-throttling added via `touchSessionIfDue` (at most 1 D1 write every 2 minutes of active use), reducing D1 writes by >85%.
  - Added `forceTouchSession` for explicit keepalive.
  - Non-mutating probes (`GET /api/admin/session`) marked with `isProbe: true` to prevent resetting idle timers on passive tab checks.
  - Added `POST /api/admin/session` keepalive endpoint with mutation authentication.
- **Client Inactivity Tracker & Modal:**
  - Implemented `src/admin/useSessionTimeout.ts` listening to user interaction events (mousemove, mousedown, keydown, touchstart, scroll).

  - Automatically clears session and redirects to login at 15 minutes of inactivity or upon reaching 12-hour absolute ceiling.

## 4. Phase 2 Implementation Summary (Cloudflare R2 Media Backend)
- **R2 Storage & CSP Configuration:**
  - Remote R2 bucket `ali-faniani-portfolio-media` created and verified.
  - Added R2 binding `MEDIA_BUCKET` in `wrangler.toml`.
  - Updated Content Security Policy in `public/_headers` to permit `https://media.alifaniani.ir` in `img-src` and `connect-src`.
- **Database Schema Migration 0005:**
  - Created `migrations/0005_media_assets.sql` tracking `id`, `r2_key`, `url`, `original_name`, `display_name`, `mime_type`, `bytes`, `width`, `height`, `category`, `associated_key`, `state`, timestamps, and indexes.
- **Media Storage Engine (`functions/lib/media-store.ts`):**
  - Strict magic-byte sniffing: authenticates WebP, PNG, JPEG, and AVIF. Rejects SVGs, executables, scripts, and spoofed extensions.
  - Automatic raster dimension extraction in binary buffers for WebP, PNG, JPEG, and AVIF.
  - Atomic compensation: automatically cleans up R2 object if D1 registration encounters any failure.
  - Safe deletion reference check: scans D1 `content` table (both published `data` and overlay `draft_data`) for the media URL or key. Rejects with HTTP 409 Conflict if referenced.
- **Media API Endpoints:**
  - `GET /api/admin/media`: Lists media with category filtering, search, and pagination.
  - `POST /api/admin/media/upload`: Multipart upload with magic-byte verification, R2 storage, D1 registration, and audit trail.
  - `GET /api/admin/media/:id`: Retrieves single asset and live/draft reference details.
  - `PATCH /api/admin/media/:id`: Metadata update (display name, category, associated key).
  - `DELETE /api/admin/media/:id`: Safe deletion with 409 reference blocking and audit logging.
  - `GET /api/admin/media/stats`: Aggregate count, byte totals, and category breakdowns.
  - `GET /media/[[path]]`: Fallback proxy route streaming from R2 with immutable cache headers.
- **Verification:**
  - 128/128 tests passing (+11 new integration tests in `tests/admin-media.test.ts`).
